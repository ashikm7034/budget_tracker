# MoneyMate AI - Google Sheets Database Setup

To use this application, you need to create a Google Spreadsheet and set up the following 8 tabs with the exact column headers specified below.

## Google Sheets Tabs Setup

Ensure that the sheets (tabs) are named **exactly** as shown, and the headers are placed in the **first row (Row 1)** of each sheet.

---

### 1. `User Settings`
This sheet stores user profiles, authentication PINs, and budget/threshold settings.

| Column | Header | Type | Description |
|---|---|---|---|
| A | `userId` | String | Unique user ID (UUID) generated by App |
| B | `email` | String | User's email address |
| C | `pin` | String | Plaintext PIN/Password for verification |
| D | `userName` | String | Display name of the user |
| E | `currency` | String | Chosen currency symbol/code (e.g., `INR`) |
| F | `emergencyThreshold` | Number | Low balance alert threshold (default: `1000`) |
| G | `createdAt` | Timestamp | User creation date/time |

---

### 2. `Expenses`
Stores all expenses logged by the users.

| Column | Header | Type | Description |
|---|---|---|---|
| A | `id` | String | Unique transaction ID (UUID) |
| B | `userId` | String | Associated User ID |
| C | `amount` | Number | Expense amount |
| D | `category` | String | Tea, Snacks, Food, Travel, College, Recharge, Shopping, Subscription, Other |
| E | `note` | String | Additional details/description |
| F | `date` | Date | Transaction date (`YYYY-MM-DD`) |
| G | `paymentMethod` | String | Cash, UPI, Card |
| H | `needOrWant` | String | Need, Want, or Unclassified |

---

### 3. `Income`
Stores all income inputs logged by the users.

| Column | Header | Type | Description |
|---|---|---|---|
| A | `id` | String | Unique income ID (UUID) |
| B | `userId` | String | Associated User ID |
| C | `amount` | Number | Income amount |
| D | `source` | String | Source description (e.g., Salary, Allowance, Gift) |
| E | `date` | Date | Income date (`YYYY-MM-DD`) |
| F | `note` | String | Additional details/description |

---

### 4. `Borrowed`
Tracks money you have borrowed from others that you need to pay back.

| Column | Header | Type | Description |
|---|---|---|---|
| A | `id` | String | Unique borrowed record ID (UUID) |
| B | `userId` | String | Associated User ID |
| C | `personName` | String | Name of the person you borrowed from |
| D | `amount` | Number | Borrowed amount |
| E | `borrowDate` | Date | Date borrowed (`YYYY-MM-DD`) |
| F | `dueDate` | Date | Expected repayment date (`YYYY-MM-DD`) |
| G | `status` | String | `Pending` or `Repaid` |

---

### 5. `Receivables`
Tracks money others owe to you.

| Column | Header | Type | Description |
|---|---|---|---|
| A | `id` | String | Unique receivable record ID (UUID) |
| B | `userId` | String | Associated User ID |
| C | `personName` | String | Name of the person who owes you |
| D | `amount` | Number | Owed amount |
| E | `date` | Date | Date lent (`YYYY-MM-DD`) |
| F | `reminderStatus` | String | `Not Sent` or `Sent` |
| G | `status` | String | `Pending` or `Repaid` |

---

### 6. `Goals`
Tracks savings goals.

| Column | Header | Type | Description |
|---|---|---|---|
| A | `id` | String | Unique goal ID (UUID) |
| B | `userId` | String | Associated User ID |
| C | `goalName` | String | EMO Robot, Laptop, Bike, Emergency Fund, etc. |
| D | `targetAmount` | Number | Target savings amount |
| E | `currentSavedAmount` | Number | Amount currently saved |
| F | `deadline` | Date | Target completion date (`YYYY-MM-DD`) |

---

### 7. `Budget`
Tracks user monthly budgets.

| Column | Header | Type | Description |
|---|---|---|---|
| A | `userId` | String | Associated User ID |
| B | `monthlyIncome` | Number | Monthly income base |
| C | `needsBudget` | Number | Budget allocated for Needs |
| D | `wantsBudget` | Number | Budget allocated for Wants |
| E | `savingsBudget` | Number | Budget allocated for Savings |
| F | `dailyLimit` | Number | Derived daily spending limit |

---

### 8. `Notifications`
Stores system alerts, low balance reminders, or AI spending alerts.

| Column | Header | Type | Description |
|---|---|---|---|
| A | `id` | String | Unique notification ID (UUID) |
| B | `userId` | String | Associated User ID |
| C | `title` | String | Title of notification |
| D | `message` | String | Detailed notification message |
| E | `timestamp` | Timestamp | When the notification was created |
| F | `isRead` | Boolean | `TRUE` or `FALSE` |
