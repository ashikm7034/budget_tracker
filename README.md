# MoneyMate AI - Budget Tracker

A premium, Apple-inspired personal finance management application built with Flutter.

## Key Features
- **Offline-First Persistence**: Save and edit records instantly with local caching.
- **Manual Cloud Sync**: Upload and synchronize all local changes dynamically to Google Sheets.
- **In-App Apple-Style Calculator**: Shared mathematical sheet widget integrated in transaction screens.
- **Combined Ledger**: Live passbook displaying combined Debit and Credit streams.
- **UPI Lite Wallet**: Dedicated sub-balance with quick load options.
- **AI Coach Screen**: Natural language parser for easy logging.
